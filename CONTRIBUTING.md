# Contributing

LinkDish is source-visible proprietary software. Public access to this
repository does not grant permission to use, copy, modify, distribute, or
deploy its contents.

## Issues

Bug reports and focused product feedback are welcome. Before opening an issue:

- search for an existing report;
- describe the expected and observed behavior;
- include a minimal reproduction when possible;
- remove credentials, personal information, private recipe data, and account
  details.

Do not report security vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.

## Pull requests

Code contributions are accepted only when requested or approved in advance by
the repository owner. An invitation to contribute to one change does not grant
broader rights to the project.

For an approved contribution:

1. Create a focused branch.
2. Add or update tests for behavior changes.
3. Run `pnpm validate`.
4. Explain the behavior, risk, and verification in the pull request.

By submitting an approved contribution, you confirm that you have the right to
submit it and agree that the repository owner may use, modify, relicense, and
distribute it as part of LinkDish.
