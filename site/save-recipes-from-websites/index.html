Saving from
websites.

Which recipe websites work with LinkDish?

Most public recipe pages work, from large food sites to personal blogs. Pages that publish their recipe in a standard recipe format import most cleanly. Pages behind a login or a paywall may not import.

Does LinkDish copy the whole article?

No. It keeps the recipe itself: ingredients, steps, times, servings and the photo, with a link back to the original page so the author keeps the credit.

What if an import misses something?

You can edit any saved recipe. If a site keeps importing badly, send the link through LinkDish Support so it can be looked at.

Is it quick?

Usually a few seconds. Links LinkDish has already read come back almost instantly.

Is it free to try?

Yes. The Free plan includes 3 recipe imports and up to 15 saved recipes, and no card is required.
